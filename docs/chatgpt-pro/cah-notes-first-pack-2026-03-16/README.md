# CAH Notes-First Pack

This pack is for the next ChatGPT Pro attempt using **lecture notes as the primary factual source**.

Why this pack exists:

- Past-question documents kept pulling ChatGPT toward near-paraphrases of already imported stems.
- The local originality screen rejected three prior batches for being too close to the source corpus.
- This pack shifts the grounding source to lecture/study notes first, with past-question documents used only as secondary concept hints.

Recommended workflow:

1. Upload the files listed in `UPLOAD_CHECKLIST.md` into one fresh ChatGPT Pro chat.
2. Paste the full text of `PROMPT_NOTES_FIRST_BATCH_01.md`.
3. Ask for one JSON reply only.
4. Paste the returned JSON back into Codex for offline validation before import.

Success criteria:

- questions are grounded in the note PDFs first
- question-source docs are used only for concept coverage or exam flavour
- stems are clearly original and not close paraphrases of imported question-bank items
