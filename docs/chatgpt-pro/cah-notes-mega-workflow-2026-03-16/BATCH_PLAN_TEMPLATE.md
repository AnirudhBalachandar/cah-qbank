# Batch Plan Template

Use this template when ChatGPT Pro creates the master plan.

## Rules

- total planned questions must be **>= 1000**
- preferred batch size: **10 to 14**
- each batch should focus on a **small number of closely related subtopics**
- broad topics should be split across multiple batches

## Suggested output structure

For each batch, include:

- `batch_id`
- `curriculum_area`
- `primary_source_priority`
- `topic_cluster`
- `subtopics`
- `target_question_count`
- `question_style_mix`
- `note_pages_or_sections`
- `question_zip_use`
- `risk_of_overlap`

Example:

```md
### Batch 01
- Curriculum area: General Paediatrics
- Primary source priority: Louisa notes first, CAH Bible second
- Topic cluster: Growth and nutrition
- Subtopics:
  - growth assessment
  - faltering growth
  - obesity
- Target question count: 12
- Question style mix:
  - 4 counselling / explanation
  - 3 investigations / interpretation
  - 3 management / follow-up
  - 2 diagnostic discrimination
- Note pages or sections:
  - Growth and Nutrition
  - Faltering Growth
  - Obesity
- Question zip use:
  - concept hint only
- Risk of overlap:
  - moderate
```
