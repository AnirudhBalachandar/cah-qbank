# Targeted Retry Pack

This folder is the next ChatGPT Pro handoff pack after two failed originality screens.

Goal:

- generate a smaller batch of genuinely original CAH SBA drafts
- stay grounded in the internal CAH source files only
- avoid repeating the 24 rejected stem/task patterns from the previous two batches

Recommended use:

1. Upload the source zip in this folder.
2. Upload `BLUEPRINT_BRIEF.md`.
3. Upload `OUTPUT_SPEC.md`.
4. Upload `REJECTED_PATTERNS_SUMMARY.md`.
5. Upload both rejected JSON batches and both dry-run reports.
6. Paste the full text of `PROMPT_TARGETED_RETRY_BATCH_03.md`.
7. Ask ChatGPT Pro for one JSON reply only.
8. Paste the returned JSON back into Codex for validation before any import.

Important:

- The previous two batches were rejected because they stayed too close to existing imported/published stems.
- This retry pack therefore prioritises originality over quantity.
- It is better to get 6 to 8 clean draft questions that pass than 24 that are rejected again.
